# 📺 AppLock for Android TV

A lightweight, secure application locker designed specifically for Android TV interfaces.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Platform](https://img.shields.io/badge/platform-Android%20TV-green.svg)
![Language](https://img.shields.io/badge/language-Kotlin-purple.svg)

## ✨ Features
* **TV-Optimized UI:** Designed for D-pad remote navigation.
* **PIN Protection:** Lock specific apps with a custom PIN code.
* **Security:** Prevent unauthorized users from changing app settings.

## 🚀 Quick Start
1. Install the APK on your Android TV.
2. Set your custom PIN (Default: `2650` or `1234`).
3. Select the applications you want to protect.
